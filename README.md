# 🔐 Como os grandes ataques históricos moldaram a cibersegurança moderna

## Contexto
Este caderno temático foi criado como parte do meu processo de 
aprendizado em cibersegurança. O tema escolhido explora como 
ataques reais e históricos — como Morris Worm, Stuxnet e WannaCry 
— não apenas expuseram vulnerabilidades críticas, mas 
transformaram práticas, ferramentas e políticas de segurança 
que usamos até hoje.

## Objetivos
- Compreender o impacto técnico dos principais ataques históricos
- Identificar quais vulnerabilidades foram exploradas em cada caso
- Conectar eventos do passado com práticas defensivas atuais
- Desenvolver vocabulário técnico sólido para entrevistas e certificações
